# FemAction-BOT

Discord-бот с РП-командами. Работает только через слеш-команды (`/обнять`).
Каждое действие описывается одним файлом в `src/actions`, из которого
автоматически строится слеш-команда.

## 1. Структура проекта

```
FemAction-BOT/
├── src/
│   ├── actions/        РП-действия (по файлу на команду: kiss, hug, pat, bite, boop, slap, lick, silly)
│   ├── commands/       Утилитарные команды (help, statistics)
│   ├── events/         Обработчики событий (interactionCreate, activity)
│   ├── lib/            Загрузчик действий, построитель ответа, кулдауны, хранилище гифок, статистика, награды, деплой команд
│   ├── config.ts       Чтение и валидация config.json
│   ├── types.ts        Интерфейсы ActionDefinition / UtilityCommand
│   └── index.ts        Точка входа
├── config.example.json Шаблон конфига (токен, гифки, награды за активность)
├── config.json         Реальный конфиг (не в git, монтируется в Docker как volume)
├── data/               Статистика активности (stats.db, SQLite, не в git, writable-volume)
├── Dockerfile          Multi-stage сборка образа (node:24-slim)
├── docker-compose.yml  Описание сервиса femaction-bot
├── tsconfig.json       Настройки TypeScript
├── package.json        Зависимости и npm-скрипты
└── README.md
```

## 2. Быстрый старт с Docker

### 2.1. Предварительные требования

- Установленный Docker (вместе с Docker Compose).

Если Docker ещё не установлен, поставь его одной командой:

```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
```

### 2.2. Установка и запуск

1. **Клонируй репозиторий:**

   ```bash
   git clone https://github.com/Alexnitro777/FemAction-BOT.git
   cd FemAction-BOT
   ```

2. **Настрой конфиг:**

   ```bash
   cp config.example.json config.json
   ```

3. **Запусти бота:**

   ```bash
   docker compose up -d --build
   ```

   При старте контейнер автоматически регистрирует слеш-команды
   (`node dist/lib/deployCommands.js`) и запускает бота.

## 3. Управление контейнером

```bash
# Просмотр логов в реальном времени
docker compose logs -f

# Остановка бота
docker compose stop

# Запуск ранее собранного контейнера
docker compose start

# Перезапуск (например, после правки config.json)
docker compose restart

# Пересборка после изменений в коде
docker compose up -d --build

# Остановка и удаление контейнера
docker compose down
```

> `config.json` смонтирован в контейнер как volume. Правки гифок и наград в
> `config.json` подхватываются «вживую» без перезапуска. Перезапуск нужен только при
> изменении секретов (`token`, `clientId`), а пересборка — при изменении кода
> или добавлении новых команд в `src/actions`. Статистика активности хранится в
> локальной базе SQLite `./data/stats.db` (смонтирована как volume) и переживает
> перезапуск контейнера. Если рядом лежит старый `./data/stats.json`, он один раз
> автоматически импортируется в базу и переименовывается в `stats.json.bak`.

## 4. Награды за активность (автовыдача ролей)

Бот считает активность каждого пользователя и автоматически выдаёт роли при достижении
порогов: участник получает **все** роли, чьи пороги выполнены (а не только верхнюю). По умолчанию
бот также **снимает** наградные роли, которым участник больше не соответствует
(`removeUnearnedRoles`, см. ниже) — например, если порог подняли или роль выдали вручную. Снятие
затрагивает только роли из `messageRoles`/`voiceRoles`, прочие роли не трогаются. Настройка — в блоке
`rewards` файла `config.json`:

```json
"rewards": {
  "messageRoles": [
    { "count": 1500,  "roleId": "ID_РОЛИ" },
    { "count": 3500,  "roleId": "ID_РОЛИ" },
    { "count": 5500,  "roleId": "ID_РОЛИ" },
    { "count": 10000, "roleId": "ID_РОЛИ" },
    { "count": 15000, "roleId": "ID_РОЛИ" }
  ],
  "voiceRoles": [
    { "hours": 100, "roleId": "ID_РОЛИ" }
  ],
  "removeUnearnedRoles": true,
  "voice": {
    "ignoreAfkChannel": true,
    "ignoreDeafened": true
  }
}
```

- **`messageRoles`** — пороги по числу сообщений; считается каждое сообщение.
- **`voiceRoles`** — пороги по часам в голосовом канале.
- **`voice.ignoreAfkChannel`** — не засчитывать время в AFK-канале сервера.
- **`voice.ignoreDeafened`** — не засчитывать время с выключенным звуком (deaf). Время с
  выключенным **только микрофоном** (mute) засчитывается.
- **`removeUnearnedRoles`** — снимать ли наградные роли, которым участник больше не соответствует.
  По умолчанию `true`. Поставь `false`, чтобы роли были чисто накопительными (раз выданная роль
  остаётся навсегда).
- Записи с пустым `roleId` игнорируются — можно включать пороги по мере готовности ролей.

### Что нужно настроить в Discord

1. **Role ID:** Настройки → Расширенные → включи «Режим разработчика», затем ПКМ по роли →
   «Копировать ID роли». Вставь в `roleId`.
2. **Право бота:** у роли бота должно быть право **«Управление ролями»**, а сама роль бота
   должна стоять в списке ролей сервера **выше** всех выдаваемых ролей — иначе Discord не даст
   их назначить.
3. Интент голосовых состояний (`GuildVoiceStates`) **не привилегированный** — включать что-либо
   в Developer Portal не нужно.

### Просмотр статистики

- `/статистика [цель]` — слеш-команда; без цели показывает твою статистику, с целью — указанного
  пользователя.

Показывает число сообщений, суммарное время в голосовых и сколько осталось до следующей роли.

> Команда `/статистика` — новая слеш-команда, поэтому её нужно зарегистрировать: при Docker-запуске
> это делает `docker compose up -d --build` автоматически, локально — `npm run deploy`.
